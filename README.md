## 📌 O que são Métodos?

Em Java, métodos são blocos de código responsáveis por executar uma tarefa específica.

Eles permitem:

- ✔ Modularização do código
- ✔ Reutilização de lógica
- ✔ Melhor legibilidade
- ✔ Separação de responsabilidades
- ✔ Manutenção facilitada
